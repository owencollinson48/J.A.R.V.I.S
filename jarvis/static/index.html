     Intelligence
    Not connected
    Use an OpenAI-compatible provider, or keep inference on your computer with Ollama. Selected conversation context and tool results are sent to this provider.
    
          
    
          
    Keys stay in your local settings file, accessible to your Windows account. Leave blank to keep your saved key. Ollama needs no key.
    Connection checks test streaming, JARVIS tools and a tool-result follow-up. Find compatible model checks models listed by your provider and saves one only after it passes; these small model requests may incur API charges.
    
          
     Computer access
    Full computer access lets JARVIS use every path your Windows account can access. Requested edits and saves keep automatic backups.
    Applications, files and commands use your Windows account’s permissions. Windows sign-ins, UAC and security controls still apply.
    
          
     Execution
    Your request authorizes the actions needed to carry it out. Automatic mode runs available tools without JARVIS approval prompts. Use Stop task, Escape or Ctrl+Alt+F8 to cancel further work.
    Current-browser mode opens a new tab and uses visible Windows controls. The separate managed profile provides richer page controls when needed.
    The app index also reads Windows registrations, Start Menu entries, packages and PATH. Extra folders are bounded scans, including portable executables. Browser tasks normally reuse your open browser and its signed-in session.
    
          
     Voice & conversation
    Click the JARVIS circle once to enable hands-free conversation. It sends your words after a pause, speaks its reply, then listens again. Use Chrome or Edge and keep this tab open.
    Natural speech uses an AI-generated voice and sends reply text to OpenAI for synthesis; API charges apply. An OpenAI chat key is reused automatically. Other chat providers need a separate OpenAI speech key. Leave blank to keep a saved key.
    Loading available voices…
    Installed voice and speed save in this browser. Natural voice settings save with Save changes or Hear a sample. No audio upload is needed. Browser speech services may process your microphone audio online. Automatic mode treats your request as approval for the available computer actions.
    
          
     Personal touches
    Keep JARVIS running for reminders. Missed reminders appear the next time it starts.
